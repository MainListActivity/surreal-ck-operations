# 老板端本地设计环境

设计师使用同一套 Preact 页面、CSS 和组件，但后端由内存数据模拟。无需数据库、Paseo、身份服务、Cloudflare 或模型账号。只运行本地服务，不需要 `.env`、`.dev.vars` 或任何生产凭证。

## 设计师启动

环境：Bun 1.3.11（或兼容版本）、pnpm 10.32.1。克隆仓库并切到包含本功能的分支后，在仓库根目录执行：

```sh
pnpm owner:demo
```

这个命令自动安装老板端依赖，并默认加载仓库内 `demo/production.snapshot.json` 的生产脱敏快照。设计师无需导出、导入或配置数据。首次安装需要访问依赖仓库；页面运行不连接生产。

打开 `http://127.0.0.1:6006`，点击「进入本地设计预览」。依赖已安装时，也可以在 `owner-end` 目录执行 `pnpm demo`。端口占用时：

```sh
pnpm owner:demo --port 6007
```

默认使用本次真实生产导出的脱敏快照，数据量及状态分布见同目录 `production.snapshot.md`。看板活动、运维、权限和执行详情仍由本地模拟器生成。`demo/data.ts` 的 `seed()` 保留为测试用的全状态示例，不与生产快照混合。

修改 `src/ui/` 下的页面和组件、`public/app.css` 后刷新浏览器即可看到变化。这里没有自动热刷新，JS 在请求时重新打包。组件目录与生产一致，不需要维护一份独立的假页面。

编辑、创建、确认、暂停、消息扣留、员工策略、笔记等操作仅修改当前服务进程内存；刷新页面保留，重启服务或点顶部「重置示例数据」恢复初始数据。同一服务进程的多个标签页共享模拟状态。确认不会真的调用模型、派工或发布。重置会丢弃本地修改。

数据库查询/写入、云端 API、主机命令、密钥生成、模型翻译和笔记整理等未模拟命令明确返回错误；运维页面仍保留这些组件，方便设计成功/失败提示及危险操作的布局。API 模拟不是业务引擎，不用于验证调度与发布的真实性。

## 项目会议室预览

总览按项目展示正在工作、受阻或执行状态待确认的员工；空闲会话不占工位。点击「切换 4 / 8 人」可添加本地并行案例并切换人数：总览 4 人以内展示人物形象，超过 4 人展示头像；进入项目后展开人物和更长的近期输出。案例包含模型、电脑、员工清单进度、预计结束区间、项目验收进度和待发消息编辑。操作仍只写内存。

总览使用紧凑会议室：员工脚下或头像外圈承载真实进度，身份、预计结束、模型、电脑和待发消息直接贴在桌沿，采样输出以短气泡展示。大屏的 8 人场景横排头像，无在岗员工的项目集中为项目目录，保留验收进度、排队与阻塞状态。进入项目后继续显示完整工位和任务资料；总览压缩不改变派工或消息编辑规则。

与在场员工存在当前任务交接的离场员工，以头像、姓名和状态保留在项目内，不占工位、不计在岗人数。连线始终连接具体员工；交接动画结束后保留淡色方向线，返工时切换到最新交接。点击「演示交接」可切换交付复核与返工场景；总览和项目详情使用相同规则。

交接线按人物、气泡、资料和进度文字的实际位置绕行，保留至少 6px 间距；标签没有足够空位时不显示。多人案例额外包含隔位、换行和离场头像交接。布局测量由 ResizeObserver 和 DOM 变化触发，并按帧合并；几何签名不变时复用路径，不因 LIVE 文本采样反复寻路。人物在窄工位自适应缩小，气泡下方保留通道；尊重系统的减少动态效果设置。

生产的员工百分比仅来自成功更新的原生工作清单，支持 Claude 的结构化清单及 Factory 的状态文本；项目百分比按已确认范围的验收任务计算，包含尚未创建的实施步骤。没有清单或足够历史耗时样本时显示未知，不以工具次数、输出字数伪造完成率或结束时间。

待发消息点击后在页面内编辑派工正文，并展开实际任务文件预览；文件预览只读，不改写已确认的需求。正文保存使用原文比较，避免覆盖其他页面的更新，已发送消息不能修改。员工旁显示的候选接收人仍由调度确定；未来复核模板标注后续步骤。

## 后续刷新生产快照（维护者操作）

本次快照已提交，设计师不需要执行下面的步骤。后续需要更新数据时：

导出由老板自己在已登录的生产浏览器完成。设计师不接触生产登录态，也不直连数据库。

1. 在仓库根目录执行 `pnpm --dir owner-end demo:export-script`，生成 `owner-end/.demo/export.js`。
2. 以老板身份登录 `https://company.maplayer.top`，打开开发者工具 Console。
3. 检查并粘贴上述文件的完整内容执行。脚本只调用固定的只读接口，不提供任意 SQL，不调用写入命令。浏览器在内存中使用当前会话授权，不向外部地址发送请求。
4. 成功后下载 `owner-design-snapshot.json`，将这个文件和代码分支交给设计师；不要交 `.env`、`.dev.vars`、会话存储或数据库备份。

快照包含产品、需求、反馈、最近 300 条执行任务、员工及笔记。需求和反馈按页读取，总量上限分别为 10000 条；超过上限或任何请求失败都停止下载，避免把失败响应当成空数据。任务超出最近 300 条的历史不包含在快照中。

导出严格采用字段白名单：客户反馈和任务/需求正文、笔记、项目与员工名称全部替换为示例文字；ID 重新映射；保留状态、数量、优先级、修订及能映射到已导出记录的关联关系。联系方式、URL、主机路径、凭证、原始审计正文和发布配置不进入文件。问题描述保留有限的长短差异，用于评估多行布局。未知字段不会复制。看板根据快照重新组装，运维和权限信息使用本地示例，不是生产配置副本。

因此这是一份供设计使用的脱敏数据快照，不是可恢复数据库备份，也不是生产所有字段的完整导出。设计师可以在本地界面修改文案来评估不同内容长度。

## 导入快照

```sh
pnpm owner:demo --snapshot /绝对路径/owner-design-snapshot.json
```

启动时再做一次白名单处理，避免手工添加的未知字段被直接带入界面。快照最大 10 MB；格式不符会停止启动，不回退连接生产。文件无需放进仓库，默认文件名已加入忽略规则。页面编辑不写回快照，重置恢复导入时的数据。

## 隔离边界

- `demo/server.ts` 只导入纯数据、模拟状态和本地构建代码，不启动 Worker，不加载 Wrangler 配置或数据库模块；启动命令关闭 Bun 自动读取 `.env`。
- 只监听 `127.0.0.1`，严格校验 Host 和 Origin，不支持外部监听或代理；未知 API 返回错误，没有生产回退。
- 浏览器 CSP 限制网络连接到同源，禁止 iframe、外部脚本和表单提交。只服务明确列出的静态文件，不暴露源码目录或环境文件。
- 模拟认证通过本地构建别名替换；正常 `build:ui` / Worker 构建不包含免登录逻辑。演示登录标记使用单独的 sessionStorage 键，不读取生产会话。
- 这是默认运行方式的隔离措施，不是约束有权修改源代码的设计师的沙箱。不给设计师生产凭证，才是生产访问控制的最终边界。

验证：`pnpm --dir owner-end typecheck`、`pnpm --dir owner-end test`、`pnpm --dir owner-end build`。设计快照导出脚本是独立产物，不放入生产 `public/`。
