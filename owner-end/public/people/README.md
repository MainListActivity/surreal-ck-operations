# 员工形象

`team-atlas.4e778a21bb0b.webp` 是为本项目生成的透明静态人物素材（原始 PNG 现以 WebP 传输），1536 × 1024，3 列 × 2 行。由 OpenAI 图像生成工具于 2026-11-10 生成，提示要求为一致视角、无文字、温暖柔和的六位办公人物。

总览和项目详情共用同一素材，CSS 取人物格子及头像区域。岗位/运行时的形象映射见 `src/ui/meeting-rooms.ts`；同编制的并行实例共享形象，用实例编号区分。图片本身不代表运行状态，光晕与状态由实际观测数据驱动。未来可替换渲染层为 GIF 或 Three.js，员工与任务身份不依赖图片。

`meeting-room.587f3ad68e38.webp` 为同一天通过内置图像工具按用户会议室参考图生成的空场景，1536 × 1024。最终提示要求：单间温暖柔和的 3D 玻璃会议室，弧形玻璃隔断、浅木圆角会议桌、空椅子、窗景与绿植；保持正面略俯视，顶部和桌前留出动态 UI 区域，不绘制人物、电脑、文字或界面。页面将此图作为房间背景，人物、光晕、气泡、消息与进度均由独立 DOM 叠加，数据变化不依赖替换背景。

`office-closeup.78cbb5a011ed.webp` 为项目近景空背景，同样使用内置图像工具生成。最终提示要求：参考用户第二张图的温暖奶油色 3D 办公室，右侧明亮窗户、两侧绿植、柔和阳光和浅色地面，中央留出员工与工位空间，不绘制人物、桌椅、文字或界面。近景的立体桌前台、人物、气泡和进度由组件渲染。

## 传输编码

三个素材均保持原始像素尺寸，使用 libwebp/cwebp 1.6.0 编码：`-q 90 -m 6 -alpha_q 100 -alpha_filter best -sharp_yuv -metadata none`。人物透明通道无损保留；解码后的 alpha 与原 PNG 逐像素一致。q88 的体积只再减少约 38 KB，因此选择 q90。未改变人物、场景内容或 CSS 裁剪坐标；原 PNG 可从 Git 历史恢复，public 不保留重复源图。

| 素材 | 原 PNG | WebP |
|---|---:|---:|
| team-atlas | 2,085,825 B | 239,708 B |
| meeting-room | 1,689,485 B | 107,102 B |
| office-closeup | 1,521,883 B | 60,228 B |

文件名后缀为文件内容 SHA256 的前 12 位。更新图片必须随内容修改文件名，并同步 `app.css`、demo 白名单、`public/_headers` 与 `public/_redirects`；仅这三个明确的摘要 URL 设置一年 `immutable` 缓存，未版本化的 app.js、app.css 与 HTML 仍按原策略重验证。三个旧 PNG URL 通过精确的 302 规则转向新图，兼容尚未刷新的页面，不对旧 URL 设置长期缓存。本地设计模式继续使用 no-store，便于刷新检查修改。
