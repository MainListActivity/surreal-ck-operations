# 员工形象

`team-atlas.png` 是为本项目生成的透明 PNG 静态人物素材，1536 × 1024，3 列 × 2 行。由 OpenAI 图像生成工具于 2026-11-10 生成，提示要求为一致视角、无文字、温暖柔和的六位办公人物。

总览和项目详情共用同一素材，CSS 取人物格子及头像区域。岗位/运行时的形象映射见 `src/ui/meeting-rooms.ts`；同编制的并行实例共享形象，用实例编号区分。图片本身不代表运行状态，光晕与状态由实际观测数据驱动。未来可替换渲染层为 GIF 或 Three.js，员工与任务身份不依赖图片。

`meeting-room.png` 为同一天通过内置图像工具按用户会议室参考图生成的空场景，1536 × 1024。最终提示要求：单间温暖柔和的 3D 玻璃会议室，弧形玻璃隔断、浅木圆角会议桌、空椅子、窗景与绿植；保持正面略俯视，顶部和桌前留出动态 UI 区域，不绘制人物、电脑、文字或界面。页面将此图作为房间背景，人物、光晕、气泡、消息与进度均由独立 DOM 叠加，数据变化不依赖替换背景。

`office-closeup.png` 为项目近景空背景，同样使用内置图像工具生成。最终提示要求：参考用户第二张图的温暖奶油色 3D 办公室，右侧明亮窗户、两侧绿植、柔和阳光和浅色地面，中央留出员工与工位空间，不绘制人物、桌椅、文字或界面。近景的立体桌前台、人物、气泡和进度由组件渲染。
