# 渠道绩效与动态新模型准入

老板要求：同款模型在不同渠道不能继承绩效。AA 能力和价格可以由公开模型映射共享；执行证据按完整渠道/模型 ID 隔离，仅剥离路由思考后缀，不剥离账号或远端渠道路径。旧评分不删不重写，恢复按原始完整 ID 读取。绩效均值、任务趋势、回退排序全部一致。

最新确认规则：最低智能分取最新版本 GPT Luna 的 Max 实测 AA 分数，取消 Sonnet low 上界，不使用固定分值。达到底线的模型，AA 输入价 ≤ $1/M 为 Haiku，> $1/M 且 ≤ $2/M 为 Sonnet；未知、无效或更高价格不自动进入员工组。Magpie 免费标签仅影响组内消耗排序，不替代 AA 输入价格作为入组条件。昂贵/未知价格模型在内部候选中归手动参考档 Opus，但不向 Opus 自动加成员。

最新版本按 Luna 名称中的数字版本排序，不取分数最高的旧版，也不受渠道映射影响。最新版本缺 Max 测量时拒绝新分组更新，保留现有配置。首次升级 AA 缓存格式触发重新拉取，之后每日刷新；失败保留上次有效快照。捆绑公开快照补齐模型名、测量等级和价格供离线回退。

这些规则作用于新增模型；保留当前有效成员和人工移除决定，不全量重建分组、不迁移既有成员。Haiku/Sonnet 不再借用对方的模型池；Opus/Fable 保留手动配置，不自动填充。旧的自动分档 override 不突破新准入规则。空组维持空组，不跨组补位。

验证：跨渠道绩效回归先红后绿；均值与趋势均不得跨渠道，保留同渠道原证据；价格边界、动态分数下调、新 Luna 版本、缺 Max 时拒绝、两组独立、手动组和已有成员不被重建。合并 main 后执行两道主机发布门禁，验证插件/服务同 SHA、健康、派工恢复与新榜单绩效样本。
