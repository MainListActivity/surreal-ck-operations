# 本机调度的资源与失败回收

`session_idle_minutes` 默认 120，设为 0 可关闭空闲会话回收。只有调度器连续观测为空闲的时间计入；首次部署不会根据旧的唤醒时间立即回收。新唤醒、turn_started、忙碌或状态未知均使旧观测失效。持有任务、贡献者绑定、待处理权限请求和未完成待办唤醒的实例保留。凭证退休事务再次校验观测和待办唤醒，成功后才归档，退休类型为正常轮换，不形成绩效扣分。

macOS 资源门禁优先使用 `kern.memorystatus_vm_pressure_level`：1 正常，2/4 暂缓派工；读不到有效等级时使用原空闲内存估计。`min_free_mem_mb = 0` 仍关闭此门禁，磁盘门禁保持原行为。

ops 工具在同一租约内连续三次收到相同权限、契约或能力拒绝，会阻塞任务并交老板处理。计数按工具隔离，成功调用清零；网络异常、5xx 不计入拒绝。计数以摘要保存在本机 comm 目录，避免记录参数、原始错误或凭证。调用按实例串行化，阻塞失败时重试阻塞而不再调用上游；旧租约响应不会阻塞后继任务。

scratch 自动回收保留注册工作树、进程打开的目录、近期嵌套文件、未提交代码和不能证明已合并的提交；任何检查失败均保留。自动回收仍遵循 `scratch_grace_hours`。只在删除成功后统计回收空间，删除失败单独记录。

`scripts/test-worktrees.ts` 为数据库与测试创建独立进程组，正常退出、SIGTERM、超时均清理整组；单次运行的临时看守进程在父进程被 SIGKILL 后清理子进程和临时数据库。没有新增常驻服务。`SCK_TEST_TIMEOUT_SECONDS` 默认 1800。测试二进制固定为本机公司 fork，测试子进程沿用启动器的 Bun。

验证入口：`bun scripts/test-worktrees.ts --all`。定向回归包括真实 fork 的租约熔断、退休保护，以及 SIGTERM、SIGKILL、超时清理；无公司 fork 的环境跳过进程清理集成测试。
