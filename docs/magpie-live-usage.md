# Magpie 统一实时用量

老板要求使用纯插件实现 Magpie 全局与会话用量，保持官方 Paseo 客户端，全部用量数据来自 Magpie，按实际请求关联终端、会话、供应商和账号。会话进行中显示等待、首响应、首文字和已确认 usage；完成后校准。全局页面提供概览、供应商/模型/终端汇总和分页明细，桌面表格、窄屏展开详情。

全部实现位于公司插件：侧边栏「Magpie 用量」及全局命令「查看 Magpie 用量」打开独立页面；agent 工作区/Explorer 面板「会话用量」及 agent 命令「查看会话用量」显示当前会话数据。会话标识直接取官方 PluginAgentPanelProps.agentId，不依赖自定义 screen params。保留旧 panel id 以兼容已打开的面板，以及原有轮末摘要。

插件只使用官方 addSurface/addSidebarItem/addWorkspacePanel/addCommandCenterItem 和 timeline 接口，不注册保留名称 usage，不修改或接管原生 Usage 页面/上下文窗口，也不注入客户端 DOM。账号、缓存、分页与实时数据接口复用既有实现，不依赖 Paseo fork 或本地客户端构建。Magpie 页面里的失败不回落官方账号数据。原生额度轮询的五分钟缓存不能用于请求实时指标。

所有 Magpie 响应都先经过字段白名单。只暴露数字计量和账号显示名/不透明标识，凭证、原始日志路径、会话正文、思考正文、工具参数不返回。关联必须精确：gateway session 或 native_session；providerKeyId 与真实账号未能核实时明确标未关联。供应商额度与筛选时间内的消耗分开，不以剩余百分比推算 token。缺失字段未知，未知价格不记免费。

实时 trace 是最近路由过程，累计和历史明细使用 Magpie 原生汇总/分页接口；重试明细与逻辑请求不重复计数。每次取有限页，筛选在服务端完成；共享短缓存、单次读取，长轮询只在页面活跃时运行，卸载取消。额度独立低频刷新，数据带时间和过期状态。公司远端数据库不进入实时读取链路，不为展示调用 JEV 或其他模型。

发布遵循私有工作树实现、针对性/完整必要检查、规格与规范审查、PR 合入 main、从 main 构建发布并核对实际运行版本。恢复备份的官方签名应用，仅重载 renderer，不重启 6767 daemon。移除本次客户端 fork 的本地工程、依赖、构建/发布产物及构建缓存；会话、员工和 Magpie 用量真源属于运行数据。
