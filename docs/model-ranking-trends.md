# 模型排序的趋势事实

排序仍由 JEV 完成，老板规则优先，Opus/Fable 保持手动。每次后台排序前读取 Magpie 的原生7天汇总与本机 usage.jsonl；请求路由不等待采集、数据库或 JEV。

每个完整供应商/模型通道分别提供首 token 延迟、生成速度、错误率、缓存命中率、首 token 超10秒比例。生成速度移植 Magpie usage.Record.DecodeOf 的计时、思考与突发释放排除规则，不使用总输出/总耗时。错误率包含没有首 token 的失败，未计时速度未知。缓存趋势是每请求命中比例；原 usage.cacheHitRate 仍是 token 加权比例。

所有指标（含最终验收绩效、AA智能分/名次、额度、输入/输出/缓存价格）使用同一结构：最新有效值、时间加权EWMA、每分钟斜率、启发式突变、7天基线、窗口分布、样本单位与新鲜度。

- EWMA：请求取最近1小时最多20条、半衰期5分钟；稀疏的任务/变动快照取最近7天最多20条、半衰期24小时。指数时间权重平均，防止历史高流量压倒最近变化。
- 斜率：同一批样本对真实时间做最小二乘回归；至少5条、覆盖1秒，重复时间不伪造斜率。
- 突变：最后10条分为前后各5条，均值变化超过25%、前批3倍标准差与单位最小阈值，后批至少4条同方向。它是启发式提示，不是显著性概率；不触发不代表稳定。过期或无法按时间区分的批次不报告突变。
- 可信度：近期最多20条、至少5条、覆盖1秒；请求最新不超过15分钟，稀疏任务/变动快照最新不超过7天。稀疏/过期数据降权；没有样本不当成零延迟、零错误。
- 窗口：15分钟、1小时、24小时、7天，提供样本数、均值、最近秩P50/P90。
- 绩效：只取最终done任务的评分，同任务多员工/别名记录按原评分权重归并成一个任务样本，非请求次数。
- AA、价格、额度：本地600权限文件只记数值变动；相同值重复读取不制造证据。初次部署没有变动历史时如实标记不足。窗口起点、最后变动时间与采样单位可供JEV判断。

字段字典、单位、计算口径和可信度说明随每次JEV请求发送。没有明确口径的老板阈值保持原usage平均值口径，不擅自改成P90、最新一次或EWMA。排序输入/输出快照保留趋势数据，Paseo和网页审核台使用同一说明文案。

读取日志失败时，原生API汇总仍可用，趋势标记不可用；采集只保留时间和数值，不持久化账号、会话、请求内容或凭证。
