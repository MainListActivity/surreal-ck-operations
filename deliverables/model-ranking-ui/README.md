# Relay Operations 全量 UI 审核原型

本目录是公司运营系统的静态交互原型，只用于设计审核。

- 不读取 SurrealDB、Magpie、JEV 或任何生产 API。
- 不包含真实账号、token 或业务数据。
- 不修改 `plugin/` 与 `src/` 中的生产实现。
- 所有数据均由 `app.js` 在浏览器端生成。

## 覆盖范围

### 老板独立审核台

- 决策收件箱：审批、退回、回复、附件与通知
- 目标与任务：进度、状态、任务下钻
- 公司手册：目录、搜索和文档阅读
- 模型排序：规则、刷新间隔、分组、模型指标与展开详情
- 给经理留言：指令编辑、优先级和历史消息

### Paseo 插件

- 插件只输出内容，不提供侧栏、顶栏或插件内页面导航，由 Paseo 宿主负责外层框架。
- 收件箱：审批、退回、问题回复与完整上下文入口
- 发目标：业务结果、边界、优先级、日期和经理拆解流程
- 目标进展：目标状态、任务树与阻塞项
- 编制：岗位职责、员工负载、在途任务与编制调整
- Magpie 用量与当前会话：核心指标、趋势、实时请求与额度
- 模型排序：规则与优先级的管理入口
- 实测与模型切换：Agent Metrics、Model Switch 摘要与完整时间线入口

## 预览

直接打开本目录下的 `index.html`，或通过仓库根页面进入。审核台左侧可切换到 Paseo 内容预览；Paseo 场景顶部的细条仅属于原型预览控制，不属于插件 UI。
